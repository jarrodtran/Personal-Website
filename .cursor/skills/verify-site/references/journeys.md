# Browser journeys for jarrodtran.com

Use 390 × 844 for a typical phone and 1280 × 800 for desktop. Repeat layout checks at 320px and 200% text when controls or text wrap change.

| Area              | Actions and evidence                                                                                                                                                                                                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Home              | Check that the name and introduction lead into Worth Mulling, then About, Work, and Contact. Confirm the desktop and phone reading order, visibility of section links, and lack of horizontal scrolling.                                                                                                            |
| Writing           | Verify subscription opens Worth Mulling on Substack. When posts are present, click a post and record the destination. Run the populated writing check in `tests/tap-targets.test.ts` and feed checks in `tests/writing.test.ts` for fixture-based validation of states the production feed does not currently show. |
| Phone menu        | Open the menu and Tab through its links. Press Escape and check that focus returns to the menu button. Reopen, pick a section, and verify the section is visible below the sticky header. Reopen and widen the viewport to check that scrolling and focus are released.                                             |
| Theme             | Check OS light and dark preferences, toggle the theme, then reload and check persistence. With JavaScript disabled, confirm the site follows the OS preference.                                                                                                                                                     |
| Case studies      | Open every case study from Work and return through the Work link. Check that the project title and article are readable in both themes and that navigation does not obscure the title.                                                                                                                              |
| Résumé            | Download the file from About and the footer. Verify each download opens as a PDF and the links resolve to the same file.                                                                                                                                                                                            |
| Contact           | Use Copy email and verify the status announcement and the address in the clipboard. Check that the email and profile links have the intended destinations.                                                                                                                                                          |
| Redirects and 404 | Open `/writing/` and `/work/` and verify their final homepage anchors. Review `/404.html` locally and confirm an unknown path on production returns HTTP 404 after release.                                                                                                                                         |

Run `pnpm a11y` on the root export for automated keyboard, focus, reflow, motion, and copy-email checks. Use a browser interaction for anything outside its assertions.
