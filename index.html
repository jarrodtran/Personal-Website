02 / How I operate

Think from first principles.
Operate as a system.

On Megapack, that meant reducing 50+ capacity requests to a ranked $23M portfolio before anyone spent. Same sequence everywhere: separate facts from assumptions, map how the system actually behaves, remove what does not serve the outcome, make ownership explicit, and install the loop that lets it scale.

  1. 01

    Ground truth

    Reduce the mandate to its outcome, constraints, economics, and assumptions.

  2. 02

    System map

    Trace the dependencies, incentives, bottlenecks, and feedback loops.

  3. 03

    Simplify

    Remove work, requirements, and complexity that do not serve the outcome.

  4. 04

    Commit

    Make the tradeoff, accountable owner, and next move explicit.

  5. 05

    Compound

    Install the cadence, feedback, and selective automation that let the system improve as it scales.
